Étape 2 : Classification du dataset

RESTRICTED (par défaut) - Accès limité au département
PUBLIC (exception) - Accès public sans restriction

Les deux types de datasets peuvent avoir des colonnes PII ou SENSITIVE

Étape 3 : Classification par colonne

PII - Données personnelles identifiables (email, téléphone, nom, etc.)
SENSITIVE - Données sensibles (médicales, financières)
